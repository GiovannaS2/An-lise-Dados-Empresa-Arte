# 📊 Sales Analysis: High-End Collectibles (BJD & Reborn)
**Projeto de Análise de Dados e Gestão de Operações**

## 🇧🇷 Descrição
Este projeto simula a análise de lucratividade de um ateliê de artes de luxo. Utilizei Python e Pandas para processar dados de vendas internacionais e Matplotlib para visualizar qual categoria de produto traz o maior retorno financeiro. 

**Objetivo:** Auxiliar na tomada de decisão estratégica de marketing e logística.

## 🇺🇸 Description
This project simulates the profitability analysis of a luxury art studio. I used Python and Pandas to process international sales data and Matplotlib to visualize which product category brings the highest financial return.

**Goal:** Assist in strategic marketing and logistics decision-making.

## 🛠️ Tecnologias (Tech Stack)
* Python 3
* Pandas (Data Manipulation)
* Matplotlib (Data Visualization)
* Jupyter Notebooks
